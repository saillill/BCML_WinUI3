# 纯净包重打核验（含「林可儿手臂修正」补丁）

## 背景

你装好独立 BNP 后把「非官方 林可儿 3.0 补丁・精简版（手臂修正）」放到了
**0101**（紧跟林可儿本体），后面全体顺移，少女动作包从 0117 变成 **0118**。

这次把**纯净包**按新顺序重打了 12 个（3 个游戏版本 × 4 个组合）。

## ⚠ 两个脚本里的硬编码清单已修正（否则会静默出错）

原先把模组**按目录名（带编号）**写死，编号一顺移就指错对象：

| 位置 | 原写法 | 后果 | 现写法 |
|---|---|---|---|
| `make_profiles_8.py` 的 `CORE` | `"0101_林可儿中文对话修正"` … | 重排后 `0101` 已是补丁，核心清单整体错位 | 去掉编号前缀按名字匹配（`_key()`） |
| 同上的 `ANIM_DIR` | `"0117_少女动作包…"` | 动画包已变 0118 → 找不到 | 同上 |
| `build_all_packs.py` 的 `OPTION_MODS` | 写死两个目录名 | 有选项的模组收不到 `applyModOptions`，选项静默停在上次状态 | 读 `info.json` 判断**有没有** `options.single/multi` |

另外修了两处：
- `make_profiles_8.py` 把第一个位置参数当输出目录 → 传 `--pure-only` 时
  配置被写进了仓库根下一个叫 `--pure-only` 的文件夹（已踩，已清理并修正）；
- 新增 `--pure-only`（只写纯净包配置）与 `build_all_packs.py --pkg <包型>`（只打某个包型）。

## 核验：补丁是否真的覆盖了本体

**关键点**：`TitleBG.pack` 里本来就有 `Model/Link.sbfres` 这些条目（本体自带），
所以「存在」不能证明补丁生效 —— 必须比对**本体值**。

| 条目 | 三个版本的本体值 | 补丁源值 |
|---|---|---|
| `Model/Link.sbfres` | `c0290c321593` | `120568b87473` |
| `Model/Armor_Default.sbfres` | `f7b615341775` | `37d4f04ec74c` |
| `Actor/Pack/GameROMPlayer.sbactorpack` | `642d3f9a0494`(1.6.0) / `3505efe2438a`(1.8.2,1.9.0) | `855bffa52665` |

12 个叶目录逐个核验（产物值 = 补丁值 **且** ≠ 本体值）：

| 叶目录 | `Link.sbfres` | `Armor_Default` | `GameROMPlayer` |
|---|---|---|---|
| 1.6.0 默认滑翔翼/有少女动作 | `120568b87473` ✓ | `37d4f04ec74c` ✓ | `eccee4a9e8ab` ✓ |
| 1.6.0 默认滑翔翼/无少女动作 | ✓ | ✓ | `00d2507772d0` ✓ |
| 1.6.0 伞形滑翔翼/有少女动作 | ✓ | ✓ | `eccee4a9e8ab` ✓ |
| 1.6.0 伞形滑翔翼/无少女动作 | ✓ | ✓ | `00d2507772d0` ✓ |
| 1.8.2 默认滑翔翼/有少女动作 | ✓ | ✓ | `f451ebbb042e` ✓ |
| 1.8.2 默认滑翔翼/无少女动作 | ✓ | ✓ | `34d340ea1ed4` ✓ |
| 1.8.2 伞形滑翔翼/有少女动作 | ✓ | ✓ | `f451ebbb042e` ✓ |
| 1.8.2 伞形滑翔翼/无少女动作 | ✓ | ✓ | `34d340ea1ed4` ✓ |
| 1.9.0 默认滑翔翼/有少女动作 | ✓ | ✓ | `f451ebbb042e` ✓ |
| 1.9.0 默认滑翔翼/无少女动作 | ✓ | ✓ | `34d340ea1ed4` ✓ |
| 1.9.0 伞形滑翔翼/有少女动作 | ✓ | ✓ | `f451ebbb042e` ✓ |
| 1.9.0 伞形滑翔翼/无少女动作 | ✓ | ✓ | `34d340ea1ed4` ✓ |

**核验不通过：0 / 12**

补充说明：

- `Link.sbfres` 与 `Armor_Default.sbfres` 是 `TitleBG.pack` 里的普通条目，合并时逐字节
  复制，所以产物值应**等于补丁源值**——实测 12/12 都是 `120568b87473` / `37d4f04ec74c`，
  且都**不等于**本体值 → 补丁确实覆盖了本体。
- `GameROMPlayer.sbactorpack` 会被 BCML 的 **actors 合并器重写**（与本体 actor 包做
  结构化合并），所以哈希必然不等于补丁源值。它的判据只能取「≠ 本体值」。
  实测按版本/动作分组稳定：1.6.0 与 1.8.2/1.9.0 不同（本体不同），
  有/无少女动作不同（动画包启用时它也会提供同名条目）——都符合预期。
- 12 个叶目录现在**全部含 `TitleBG.pack`**。以前「原版伞 + 无少女动作」是没有这个
  文件的（没有任何模组改它）；现在补丁改它，所以出现了 —— 这也是补丁生效的旁证。

## 未处理：增强包仍是旧状态

按你的要求只重打了**纯净包**。但请注意：

- 增强包的 `配置.json` 仍写着**旧编号**（如 `0101_林可儿中文对话修正`、
  `0117_少女动作包…`），这些目录现在都不存在了；
- 增强包产物里也**没有**手臂修正补丁。

如果你要把增强包也更新到新顺序 + 补丁，一条命令即可（约 6 分钟）：

```
publish\win-x64\runtime\python39\python.exe tools\make_profiles_8.py
publish\win-x64\runtime\python39\python.exe tools\build_all_versions.py --pkg 增强包
```

（第一条不带 `--pure-only` 才会连增强包的配置一起刷新。）
