  • 「原版伞」是真原版。伞模型 = 387d48135983、 贴图 = 27731b98b16a，与游戏本体 解包\1.9.0\...\Pack\TitleBG.pack 逐字节一致。
  • 「伞形伞」在两种动作下是两套不同的伞（受模组结构限制，二者互斥）：
    • 有少女动作 → 动画包的 Paraglider_L3（08a81f6b2450）
    • 无少女动作 → 林可儿的 Umbrella Glider（719b43865de3）
  • 为什么必须互斥：林可儿洋伞与动画包 Paraglider_L3 都提供 Item_Parastole2 与 Player_Animation， 内容各不相同。同时启用会被合并器按优先级二选一， 产生「洋伞模型 + 原版滑翔动作」的错配 —— 表现就是走路时头部乱转。
  • 纯净包 / 原版伞 / 无少女动作没有 TitleBG.pack： 会改该文件的模组都没参与，属正常。
