## 二、本轮新发现（首轮审计遗漏）

### 2.1 `test_reorder_sandbox.py` 的运行陷阱

```text
# 普通 Python：
ModuleNotFoundError: No module named 'bcml'   → exit 1

# 内嵌运行时：
publish\win-x64\runtime\python39\python.exe tools/test_reorder_sandbox.py
  → 4 个目录都被处理 / 没有目录丢失 / 模组顺序 = 请求顺序
  → 优先级连续 100..103 / id 已同步重写 / 无残留 __tmp_ 目录
  → 空顺序 moved=0 / 不存在目录被跳过 / 幂等：重复执行结果不变
  全部通过（退出 0）
```

**问题**：脚本自身没有把内嵌运行时加到 `sys.path`，也没有在文档里写明"必须用内嵌 python39 跑"。
任何人直接 `python tools/test_reorder_sandbox.py` 都会以为测试挂了（其实是环境不对）。

**验收标准**：脚本开头自检 `bcml` 可导入；不可导入时打印明确指引（"请用 publish/win-x64/runtime/python39/python.exe 运行"）而非抛裸 ModuleNotFoundError。

### 2.2 组合框 / 部分按钮缺无障碍名（真实缺陷）

UIA 实测（非源码推测）：

| 页面 | 控件类型 | 总数 | 有名字 | 无名字 |
|---|---|---|---|---|
| 设置 | ComboBox | 3 | **0** | 3（`GameLangBox` / `UiLangBox` / `ThemeBox`） |
| 工具 | ComboBox | 3 | **0** | 3（`RstbModBox` / `CompareLeftBox` / `CompareRightBox`） |
| 全页 | 导航汉堡按钮 | 1 | 0 | 1（`[]`，无名字） |
| 设置 | Button | 31 | 22 | 9（含路径行运行期才赋 label 的按钮） |

源码侧确认：这三个设置页下拉**都有 `x:Name`，但都没有 `AutomationProperties.Name`**，
`ApplyLanguage()` 里也没有补。屏幕阅读器会读成"组合框"，用户无法知道是"游戏语言 / 界面语言 / 主题"。

**验收标准**：每个 `ComboBox` 在 `ApplyLanguage()` 里补
`AutomationProperties.SetName(box, Loc.T("<对应标签>"))`；工具页三个同样处理。

### 2.3 工具脚本自身的健壮性缺陷

`tools/invoke_button.ps1 -List` 在遇到**虚拟化/屏外元素**时崩溃：

```text
无法将值 "∞" 转换为类型 "System.Int32"
```

原因：屏外项的 `BoundingRectangle` 为 NaN/∞，脚本直接 `[int]$r.X` 转换。
这会让"列按钮"这一基础调试动作在正常状态下就报错，掩盖真实输出。

**验收标准**：打印坐标前判断 `[double]::IsInfinity($r.X) -or [double]::IsNaN($r.X)`，屏外项标注 `[offscreen]` 而不是崩。

## 三、方法学教训（我这轮自己犯的错，记录以免重犯）

**误判过程**：实测到"上移后 UI 顺序变了"，我随即 `ls` 模组目录，看到 `0102_林可儿珠宝饰品补充` 仍在第 3 位，
于是判断"**没落盘**"，几乎写下一条"严重 bug"。

**纠错**：继续查 `backend.log`，发现 `16:42:03.867 顺序已保存：17 个目录已重命名（后端 149 ms）`。
再看一遍我的 `ls` 输出才明白 —— 我看的**就是落盘后的结果**：被上移的那一项恰好变成 `0102`，
我把它错认成"没动"。若当时停在第一次判断，就会产出一条假缺陷。

**另一处**：测 `test_reorder_sandbox.py` 退出码时，我用 `cmd >/dev/null; echo $?`，
`$?` 取到的是 `echo` 自身而非脚本的退出码，先得出"失败却退出 0"的错误结论；
改用重定向到文件再单独取 `$?` 才测准（真实为 1）。

**结论**：注释不可信，**我自己的第一手读数同样不可信到需要复测**。凡涉及"通过/失败""落盘/没落盘"的判定，
必须①拿到退出码/日志原文 ②确认比对基准没有错位。本轮所有 ✅ 均按此标准复核过。
